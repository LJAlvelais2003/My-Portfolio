# Leo Alvelais

A collection of electrical engineering projects I have worked on individually and with others. Most if not all of the projects revolve around wireless communications and antennas/antenna arrays.

## How to navigate

1. Select a project below to open its README and view the description and figures.
2. Use the project's **Files** section to open its report, simulation model, or source code.
3. Download the repository ZIP when you need several files. Keep the folder structure intact.

| Project | Description |
| --- | --- |
| [Archimedean Spiral Array](My%20Portfolio/antenna-designs/archimedean-spiral-array/) | Two 3 x 3 arrays with vertically integrated Klopfenstein and exponential baluns. Simulation and measured input matching are compared. |

# Figure Style

The plots use a conventional engineering presentation: white backgrounds, regular 8-point Arial or Times New Roman,
clear axes, and line weights of 0.5-1.0 point. Captions sit below the graphics.

Color is used for the portfolio figures. The generated array-factor curve uses MATLAB's familiar blue, with a gray
dashed reference. Aperture weights use a blue-green-yellow amplitude scale. Original simulation figures, schematics,
layouts, and photographs retain their source colors.

Typography, line weights, dimensions, and export quality follow the supplied graphics reference.
The portfolio figures use color.

The two regenerated aperture plots have embedded fonts in PDF and EPS exports, and RGB TIFF versions at 600 dpi.
Their original numerical calculations are preserved. Native HFSS/ADS screenshots retain their existing labels and
resolution; TIFF export does not add source detail.
